# Sharayu Frontend Modules

Implemented frontend modules:

- Crops: searchable/filterable crop library with crop detail modal.
- Farming Tools: interactive seed, fertilizer, irrigation and profit calculators.
- Diseases & Pests: searchable issue library with disease/pest filtering and management detail modal; ready for image-diagnosis API integration.
- Soil & Fertilizers: soil pH quick check, organic-carbon input, nutrient deficiency guide and responsive information sections.
- Government Schemes: searchable/filterable scheme directory with official information links; ready for API replacement.

These pages are frontend-first and do not modify the server/database contracts.
